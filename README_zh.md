# 物理沙盒（单文件 HTML 物理实验室）

单文件、零依赖的物理沙盒。双击 `a.html` 即可游玩：无需构建、无需服务器、无需联网。

A zero-dependency, single-file HTML physics sandbox. Open `a.html` in a browser — no build, no server, no network.（英文版见 `README.md`）

---

## 快速开始

```text
双击 a.html → 浏览器打开（推荐 Chrome / Edge，需支持 backdrop-filter 毛玻璃效果）
```

- **拖出**：从右侧字母面板把符号拖到画布
- **合成**：字母接触即合成公式（严格成对）
- **双击**：墙 / 小车 / 弹簧 双击打开控制面板；字母双击拆分
- **右键**：复制实体；拖进 🗑 删除；垃圾桶双击清空全部

## 功能一览

### 一、重力方向系统
- 9 个方向：上、下、左、右 + 四个对角 + 无重力
- 大小：地球 9.8 / 月球 1.62 m/s²；选「无重力」自动隐藏大小选项
- 除黑洞、固定构件（墙/弹簧等）和拖拽中的物体外，画布一切实体均受重力

### 二、字母面板（可移动 / 可缩小）
- 面板可拖到画布任意位置
- 点「−」折叠成圆形图标，圆标同样可拖动；点圆标展开

### 三、自定义墙壁
- **直墙**：可任意角度旋转；**弯墙**：可左右翻转、可调弯曲角度（20°~330°）
- 双击面板：反转（弯墙）、弯曲角度、旋转角度、摩擦力、删除
- 有真实碰撞体积：小球、滑块、小车、字母都会在上面反弹或滚动
- 墙可拖动、可删除

### 四、小球 + 滑块
- 圆形刚体（小球）与矩形刚体（滑块）
- 受重力方向影响、与墙和物体碰撞、带角速度自由旋转
- 小球贴墙滚动会随速度自转

### 五、抛物线轨迹
- 顶栏「轨迹」开关
- 开启后显示小球、滑块、小车的运动轨迹（实体本色 + 渐隐拖尾）
- 无重力时不显示；关闭即清除历史轨迹

### 六、弹簧
- 两端各自三态：**不固定（自由）/ 固定位置 / 绑定物体**（小球、滑块、小车、公式）
- 双击面板可设：**原长、最小长度、拉开的力(N)、压缩的力(N)**，并实时显示当前力
- 长度限制：压到最小长度即止；超过原长 2 倍断裂；拉力/压力超设定值断裂
- 断裂时粒子爆开 + 震屏；弹簧可把小车吊在空中；支持 ↻ 旋转

### 七、小车
- 车身 + 底部双轮，轮子随运动转动（有轮速与车身耦合）
- 双击面板设置**轮子半径（cm）**，改完立刻改变落地高度
- 弹簧可以固定到小车上；受重力方向影响

### 八、保存 / 加载（JSON）
- **💾 保存**：全场景导出为 `physics_sandbox_时间戳.json`
- **📂 加载**：选择 JSON 文件恢复场景
- 保存内容：全部实体及参数 + 重力方向与大小 + 轨迹开关 + 所有设置
- 弹簧绑定端按实体引用存储，载入时自动重链；载入会清理粒子/冲击波等瞬态

### 九、设置（⚙）
| 设置项 | 范围 / 默认 | 说明 |
|---|---|---|
| mc² 爆炸半径 | 100~800 px / 300 | 同步缩放冲击波物理范围与爆炸粒子规模 |
| mc² 爆炸时间 | 0.3~5.0 s / 1.1 | 炸弹倒计时，到时爆轰 |
| 旋转按钮消失延迟 | 0~5000 ms / 1500 | 鼠标离开实体后 ↻ 手柄停留时间，防止「点不到」 |
| 提示栏材质 | 普通 / 亚克力 / 液态玻璃 / 云母 | 底部提示栏皮肤 |
| 物品栏材质 | 普通 / 亚克力 / 液态玻璃 / 云母 | 右侧字母面板皮肤 |

- 两个材质**各自独立**选择；全部设置随存档一起保存/恢复，越界值自动钳制

## 公式实验室

- 接触即合成 · 严格成对（mc² 需 m+c+c 或 m+c²）
- `mg` 受重力下落 · `mc²` 质能炸弹 · `E = mc²` 生成黑洞 · `½mv²` 撞墙掉落弹性碰撞碎片
- 单字母 `E` / `B` 生成电磁场 · `μ` 摩擦场 · 拖 `t` 到 g/q/v 上组合
- 黑洞有潮汐撕裂、吸积盘与吞噬效果；高速/落地/靠近黑洞会使多字公式断裂
- **公式图鉴**按钮可查全部配方与说明

## 开发与测试

- 源码为单个 `<script>` 块，回归测试位于开发沙箱：
  - `extract.js` — 提取脚本并做语法检查
  - `s4_smoke.js` — 113 项断言：断裂、墙、球/滑块、小车、轨迹、弹簧
  - `bh_smoke.js` — 黑洞 / 场 / 合成完整性回归
  - `s5_smoke.js` — 50 项断言：存档往返、越界钳制、爆炸半径、引信时间、手柄延迟、材质
- 每个阶段在 `back/a_<时间戳>_<阶段>.html` 留一份不覆盖备份
